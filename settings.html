네이버 쇼핑 API 설정

  1. developers.naver.com에 네이버 아이디로 로그인 → Application → 애플리케이션 등록
  2. 사용 API에서 검색을 고르고, 환경 추가에서 WEB 설정을 고른 뒤 URL에 http://localhost 입력
  3. 등록 후 나오는 Client ID와 Client Secret을 아래에 붙여 넣기

Secret은 이 컴퓨터에 암호화해서 저장됩니다. 하루 호출 한도는 25,000회이며, 같은 키를 쓰는 모든 직원이 함께 씁니다.
직원용 키 파일은 직원 PC의 브라우저 폴더(C:\naver-claude-browser)에 넣고 브라우저를 켜면 자동 등록되고 파일은 지워집니다. 이 파일에는 비밀 키가 그대로 들어 있으니 사내 메신저·메일로만 전달하고, 외부에 올리지 마세요.
