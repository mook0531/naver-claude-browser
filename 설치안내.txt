네이버 + Claude 브라우저 설치 안내
====================================

이 브라우저를 설치하면 Claude 앱이 네이버 검색, 네이버 부동산, 네이버 광고 화면을
직접 열고 읽고 정리해 줍니다. 컴퓨터마다 한 번만 설치하면 됩니다.


[준비] 처음 한 번
-----------------
1. Node.js 설치
   https://nodejs.org  →  LTS 버튼 → 설치 (계속 "다음")

2. Claude 데스크톱 앱 설치 후 본인 계정으로 로그인
   https://claude.ai/download
   ※ 유료 요금제(Pro 또는 Max)가 필요합니다.


[설치] 더블클릭 한 번
---------------------
1. 받은 ZIP 파일을 C:\ 에 압축 풀기
   → C:\naver-claude-browser 폴더가 생깁니다.

2. 폴더 안의  설치(Windows).bat  더블클릭
   - 처음에는 몇 분 걸립니다.
   - "Claude 앱이 실행 중입니다" 가 나오면
     Ctrl+Shift+Esc → 작업 관리자 → Claude → 작업 끝내기 → Enter
   - 끝나면 바탕화면에 "네이버 Claude 브라우저" 아이콘이 생깁니다.


[네이버 쇼핑 API 키] 담당자에게 받은 경우만
-------------------------------------------
담당자에게 받은  naver-api-key.json  파일을
C:\naver-claude-browser 폴더에 넣고 브라우저를 켜면 자동 등록됩니다.
(등록되면 파일은 자동으로 지워집니다. 이 파일을 다른 사람에게 보내지 마세요)


[사용]
------
1. Claude 앱 실행 → Code 화면 → "로컬" 세션 열기 (클라우드 세션 X)
2. "네이버에서 오늘 날씨 검색해 줘" 라고 입력
3. 처음 한 번 도구 사용 허락 창이 뜨면 "항상 허용"

예시
- "네이버 부동산에서 ○○아파트 매매 매물 표로 정리해 줘"
- "○○, △△ 단지를 탭 두 개로 띄워서 시세 비교해 줘"
- "네이버 광고 캠페인 현황 정리해 줘" (광고는 브라우저에서 직접 로그인 먼저)
- "네이버 쇼핑에서 갤럭시북4 최저가 10개 표로 정리해 줘"


[꼭 지켜 주세요]
----------------
- 네이버/네이버 광고 로그인은 브라우저 창에서 본인이 직접 하세요.
  (Claude는 비밀번호 칸을 건드릴 수 없게 되어 있습니다)
- Claude가 저장·삭제·켜기/끄기 버튼을 누르려 하면 확인 창이 뜹니다.
  내용을 읽고 맞을 때만 "허용"을 누르세요.
- 비즈머니 충전 같은 결제는 직접 하세요.
- 필요한 만큼만 조회하세요. 네이버는 자동 대량 수집을 금지합니다.
- 회사 정보를 다루므로 Claude 설정 → 개인정보보호에서
  "Claude 개선에 도움 주기(모델 학습에 데이터 사용)"를 꺼 두세요.


[문제가 생기면]
---------------
- 폴더 안의  연결확인(Windows).bat  실행 → 화면을 캡처해서 담당자에게 보내기
- 폴더를 옮겼다면  설치(Windows).bat  을 다시 실행
- 새 버전을 받으면 같은 폴더에 덮어쓰기 후  설치(Windows).bat  다시 실행
