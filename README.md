# 네이버 + Claude 브라우저

네이버(또는 아무 사이트)를 보면서, 지금 보고 있는 페이지 내용을 Claude에게 보내 요약·정리·질문할 수 있는 데스크톱 브라우저입니다. (Electron + Anthropic SDK)

## 한 번에 설치 (Windows)

1. [Node.js LTS](https://nodejs.org)와 [Claude 데스크톱 앱](https://claude.ai/download)을 설치하고 Claude에 로그인합니다(유료 요금제 필요).
2. 이 폴더를 `C:\naver-claude-browser`에 두고 **`설치(Windows).bat`** 을 더블클릭합니다.
   브라우저 설치 → 바탕화면 아이콘 → Claude 앱 연결까지 한 번에 끝납니다.
3. 직원에게 나눠 줄 때는 ZIP과 함께 **`설치안내.txt`** 를 보내세요.

## 실행 방법 (쉬운 버전)

1. **Node.js 설치** (처음 한 번만): https://nodejs.org 에서 왼쪽 **LTS** 버튼을 눌러 받아 설치합니다. 설치 중에는 계속 "다음"만 누르면 됩니다.
2. **프로그램 받기**: 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 받은 파일을 바탕화면에 압축 풀기.
3. **실행**: 압축 푼 폴더에서
   - Windows: `실행(Windows).bat` 더블클릭
   - Mac: `실행(Mac).command` 우클릭 → 열기
   처음 한 번은 필요한 파일을 설치하느라 몇 분 걸립니다. 다음부터는 바로 열립니다.
4. **API 키 넣기** (처음 한 번만): 앱 오른쪽 위 ⚙ 버튼 → https://console.anthropic.com 에서 받은 키(`sk-ant-...`)를 붙여넣고 **저장**.

터미널을 쓰신다면 `npm install` 후 `npm start`로도 실행할 수 있습니다.
API 키는 OS 키체인으로 암호화되어 저장되며, 환경변수 `ANTHROPIC_API_KEY`가 있으면 그것을 우선 사용합니다.

**바탕화면 아이콘**: `바탕화면아이콘만들기(Windows).bat`을 실행하면 바탕화면과 시작 메뉴에 '네이버 Claude 브라우저' 바로가기가 생깁니다. 다음부터는 아이콘을 더블클릭해서 여세요(까만 창 없이 열림).

## 사용법

- 주소창: URL을 입력하거나 검색어를 입력하면 네이버 검색으로 이동합니다. `N` 버튼은 네이버 홈.
- **현재 페이지 내용 첨부**를 켜면 페이지 텍스트가 질문과 함께 Claude에게 갑니다.
  페이지에서 텍스트를 드래그해 선택하면 선택한 부분만 보냅니다.
- 블로그·카페처럼 본문이 iframe 안에 있는 페이지도 같은 도메인이면 본문까지 읽습니다.
- 빠른 버튼: 요약 / 표로 정리 / 항목 추출. 대화는 이어지며 `새 대화`로 초기화합니다.

## Claude 앱에서 이 브라우저 사용하기 (MCP)

Claude 데스크톱 앱이 이 브라우저를 직접 조작해 네이버 검색·네이버 부동산 정보를 가져오게 할 수 있습니다.
Claude 구독으로 동작하므로 API 키나 추가 비용이 필요 없습니다.

1. `실행(Windows).bat`으로 브라우저 앱을 **한 번 실행**합니다 (앱 위치가 기록됩니다).
2. Claude 앱을 **완전히 종료**하고 `Claude연결(Windows).bat`(Mac은 `Claude연결(Mac).command`)을 실행한 뒤 Claude 앱을 다시 켭니다.
   - 이 폴더를 로컬 마켓플레이스로 등록하고 `naver-browser` 플러그인을 설치합니다(공식 Claude Code CLI 사용). **설정 → 플러그인**에 `naver-browser (로컬 개발)`로 보입니다.
   - Claude 앱의 **Code / Cowork** 세션에서 쓸 수 있습니다. 폴더를 옮기면 이 파일을 다시 실행하세요.
   - 예전 Claude 데스크톱 앱(확장 프로그램 메뉴가 있는 버전)은 **설정 → 확장 프로그램**에서 `naver-browser.mcpb`를 설치하세요.
   - 연결 상태는 `연결확인(Windows).bat`으로 볼 수 있습니다.
3. Claude 앱에서 "네이버에서 ○○ 검색해 줘", "네이버 부동산에서 ○○아파트 매매 매물 정리해 줘"처럼 요청합니다.
   처음에는 도구 사용 허락 창이 뜹니다. **항상 허용**을 누르세요.
4. 브라우저 앱이 꺼져 있으면 Claude가 자동으로 실행합니다. Claude가 조작하는 동안 오른쪽 패널 위에 주황색 표시가 나옵니다.

**항상 이 브라우저를 쓰게 하려면**: 플러그인에 "네이버 정보는 항상 naver-browser 사용" 스킬이 들어 있습니다. 그래도 다른 도구를 쓰면 Claude 앱의 설정 → 일반 → "Claude가 응답할 때 고려해야 할 개인 선호 사항"에 아래 문장을 넣으세요.

> 네이버 검색, 네이버 뉴스·블로그·카페, 네이버 부동산 정보가 필요하면 웹 검색 대신 항상 naver-browser 도구를 사용해.

Claude가 쓸 수 있는 도구: `naver_search`, `navigate`, `get_page_text`, `read_page`, `find`, `click`, `type_text`, `press_key`, `scroll`, `scroll_to`, `set_value`, `screenshot`.

**네이버 광고 설정 맡기기**
- 브라우저 창에서 네이버 광고에 **직접 로그인**한 뒤, Claude에게 원하는 설정을 말하세요.
- Claude는 바꿀 내용을 표로 보여주고 승인을 받은 뒤 진행합니다.
- 탭 바 오른쪽 **확인 창: 끔/켬** 버튼으로, Claude가 저장·등록·삭제·켜기/끄기 버튼을 누르기 전에 확인 창을 띄울지 정합니다(기본: 끔). 켜 두면 **허용**을 눌러야만 실행됩니다(2분 안에 답이 없으면 거부).
- 비밀번호 입력란은 Claude가 조작할 수 없습니다. 비즈머니 충전 같은 결제는 직접 하세요.

**탭**: 위쪽 탭 바의 **+**(Ctrl+T)로 새 탭, **×**(Ctrl+W)로 닫기, Ctrl+Tab으로 전환합니다. 새 창으로 여는 링크는 새 탭으로 열립니다(Ctrl+클릭은 뒤쪽 탭, Shift+클릭은 새 창).

**북마크 (크롬처럼 폴더)**: 주소창 옆 **☆**(Ctrl+D)로 추가하면 저장할 폴더를 고르는 메뉴가 뜹니다. 북마크 막대의 **📁 폴더**를 누르면 펼침 메뉴(하위 폴더, **모두 새 탭으로 열기**)가 나옵니다. 우클릭으로 이름 바꾸기·**폴더로 이동**·새 폴더·삭제, 막대 빈 곳 우클릭으로 새 폴더. 북마크 클릭: 현재 탭, Ctrl/가운데 클릭: 새 탭, Shift+클릭: 새 창. 모든 창이 같이 쓰며 `bookmarks.json`에 트리로 저장됩니다(예전 형식은 자동 변환). **⤓ 크롬에서 가져오기**는 크롬의 폴더 구조 그대로 가져옵니다(기타·모바일 북마크는 같은 이름의 폴더로). Claude도 `list_bookmarks`(폴더별) · `add_bookmark`(폴더 지정)로 씁니다.

**네이버 쇼핑 (공식 API)**: Claude는 쇼핑 가격·최저가를 네이버 공식 검색 API(`naver_shopping_search`)로 가져옵니다. 처음 한 번 Alt → 파일 → **네이버 쇼핑 API 설정**에서 [developers.naver.com](https://developers.naver.com)의 Client ID/Secret을 넣으세요(회사 아이디로 만든 키 하나를 함께 씀, 하루 25,000회).
직원 PC에는 설정 창의 **직원용 키 파일 만들기**로 만든 `naver-api-key.json`을 브라우저 폴더에 넣고 브라우저를 켜면 자동 등록되고 파일은 지워집니다. 이 파일은 비밀 키가 들어 있으므로 사내로만 전달하세요(`.gitignore`에 포함).

**크롬에서 열기**: 지금 페이지를 기본 브라우저(크롬)에서 열려면 Ctrl+Shift+O. 네이버 쇼핑처럼 이 브라우저의 접속을 제한하는 페이지에 쓰세요.

**주소창 자동완성**: 글자를 치면 북마크(★)와 방문 기록(🕘)에서 맞는 페이지를 추천하고, 주소 앞부분이 맞으면 크롬처럼 나머지를 미리 채웁니다(한글 조합 중에는 채우지 않음). ↑/↓로 고르고 Enter, Esc로 닫기. 방문 기록은 이 PC의 `history.json`에만 저장되며 Alt → 파일 → **방문 기록 지우기**로 지웁니다.

**단축키**: Ctrl+T 새 탭, Ctrl+W 탭 닫기, Ctrl+N 새 창, Ctrl+Tab 탭 전환, Ctrl+D 북마크, Ctrl+Shift+L 대화창, F5 새로고침. 메뉴 막대는 Alt를 누르면 보입니다.

**여러 Claude 대화 동시 사용**: Claude 대화(세션)마다 자기 작업 탭을 갖습니다. 첫 대화는 보고 있는 탭에서, 다음 대화부터는 자기 창을 새로 열어(포커스를 뺏지 않음) 그 안에서만 작업하므로 서로 섞이지 않고 동시에 진행됩니다. "지금 보는 화면"을 시키면 Claude가 `use_current_tab`으로 그 탭을 가져옵니다. 탭 목록 표시: ▶ 이 대화의 탭, 👁 사용자가 보는 탭, 🤖 다른 대화의 탭. 30분 쓰지 않은 대화의 탭은 다른 대화가 이어 쓸 수 있습니다.

**여러 창**: 탭 바 오른쪽 **⧉ 새 창**(Ctrl+N)으로 창을 더 엽니다. 브라우저가 켜져 있을 때 바탕화면 아이콘을 다시 눌러도 새 창이 열립니다. 창마다 탭이 따로 있고, 창의 마지막 탭을 닫으면 그 창이 닫힙니다.

Claude도 `list_tabs` · `new_tab` · `new_window` · `switch_tab` · `close_tab`으로 여러 창과 탭을 오가며 페이지를 비교할 수 있습니다. Claude는 사용자가 마지막으로 본 탭을 조작합니다.

**창 배치**: 브라우저는 화면 **오른쪽 절반**에 열립니다. 앱 안의 대화창은 주소창 옆 **💬 대화창** 버튼, 대화창 위의 **»** 버튼, 또는 **Ctrl+Shift+L**로 열고 접습니다.

**안전장치**
- 서버는 내 컴퓨터 안(127.0.0.1)에서만 열리고, 앱이 만든 비밀 토큰이 있어야 접속됩니다.
- http/https 주소만 열 수 있고, 페이지 안의 JavaScript 실행·파일 업로드 기능은 없습니다.
- 이 브라우저에서 네이버에 로그인해 두면 Claude도 로그인된 상태로 조작하게 됩니다. 로그인하지 않고 쓰는 것을 권장합니다.
- 네이버는 자동 대량 수집을 약관으로 금지합니다. 개인적으로 필요한 만큼만 조회하세요.

## 구조

| 파일 | 역할 |
|---|---|
| `main.js` | 창 생성, API 키 저장, Claude API 호출(스트리밍), MCP 서버 시작 |
| `browser-driver.js` | 브라우저 조작(이동, 읽기, 클릭, 입력, 스크롤, 캡처) |

화면 구조: 위쪽 화면(탭 막대·주소창·북마크·대화창)은 `index.html`, 페이지는 탭마다 main 프로세스의 `WebContentsView`로 그 아래에 붙입니다(예전 `<webview>` 방식은 Windows 한글 입력과 충돌).

| 파일 | 역할 |
|---|---|
| `mcp-server.js` | Claude 앱용 MCP 서버 (127.0.0.1, 토큰 인증) |
| `mcp-bridge.js` | Claude 앱 ↔ 브라우저 연결 다리, 브라우저 자동 실행 |
| `naver-browser.mcpb`, `extension/` | Claude 앱 확장 프로그램 (다시 만들기: `npm run build:extension`) |
| `claude-plugin/`, `.claude-plugin/` | 새 Claude 앱용 플러그인(MCP 서버 + 사용 안내 스킬)과 마켓플레이스 |
| `create-shortcut.js`, `assets/` | 바탕화면·시작 메뉴 바로가기와 아이콘 |
| `bookmarks.js` | 북마크 트리 저장소(폴더, 이동, 크롬 병합) |
| `setup-claude.js` | Claude 앱 설정에 연결 등록 (기존 설정 백업) |
| `check-claude.js` | 연결 점검 |
| `preload.js` | 화면에 노출하는 안전한 IPC API |
| `renderer.js` | 브라우저 조작 버튼, 페이지 텍스트 추출, 채팅 UI |
| `index.html`, `style.css` | 화면 |
| `scripts/install-electron.js` | Electron 설치(보안 정책으로 막히면 대체 방법) |

## 모델 선택

오른쪽 패널 위의 목록에서 고를 수 있고, 고른 모델은 기억됩니다.

| 모델 | 가격 (100만 토큰당 입력/출력) | 용도 |
|---|---|---|
| Haiku 5.5 (기본) | $0.10 / $0.50 | 요약·정리 같은 일상 작업. 가장 저렴 |
| Sonnet 5.5 | $2 / $10 | 더 꼼꼼한 분석 |
| Opus 5.5 | $4 / $20 | 가장 어려운 질문 |

Haiku는 질문이 10만 토큰을 넘으면 $0.50 / $2.50으로 올라갑니다. Sonnet·Opus는 안전 분류기가 거절하면 서버가 다른 모델로 자동 재시도합니다(`fallbacks: "default"`).
